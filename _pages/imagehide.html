    About this demo
    

      

        What it is. Live demo of the MWIP watermark — an invertible
        neural network embeds an 896-bit payload (H = 128-bit perceptual hash,
        sig = 512-bit Ed25519, pk = 256-bit public key) into an
        image, and a sibling network recovers it after channel distortion.
      

      

        Demo caveat. The keypair ships in this page; anyone can forge a
        valid signature. Real deployment uses device-bound secret keys. The pHash is a
        placeholder.
      

      

        Where this runs. ONNX Runtime Web in a Web Worker, on your
        device. Your image is never uploaded. Out of scope for the current
        model: crop, rotate, Gaussian noise, Gaussian blur.
      

      

        Image size cap. The decoder allocates ~12 MB of float32 per
        megapixel plus intermediates. The demo caps inputs at 0.5 MP on mobile,
        1 MP on desktop so Safari's ~300 MB tab budget holds. The model itself
        has no such limit.
